YOUR DATA, YOUR CHOICE

Privacy first.
By design.

Updated November 19, 2026 · Applies to Markflow v2.0.0

Markflow is a Chrome extension for creating highlights, comments, replies, sticky notes, image-region comments, and drawings on webpages. The extension is designed to work locally, without a Markflow account or cloud service.

Data handled

Markflow accesses the URLs of webpages you visit and processes selected text and surrounding text anchors, user-written comments and replies, sticky notes, drawings, colors, formatting, timestamps and annotation preferences.

Where it is stored

Annotations are stored in IndexedDB belonging to the extension's origin, on the local Chrome profile. Chrome extension local storage is used for visibility and layer preferences and for migrating previously saved annotations. Personal collections and annotation layers are stored locally. JSON backup files are downloaded only when requested by the user. The extension does not intentionally upload your annotations to a Markflow server or sync them across devices.

Data sharing

Markflow does not include third-party advertising or analytics SDKs. The content script runs on supported websites and interacts with the page locally. The websites you browse may have their own tracking or network behavior, which is not controlled by Markflow.

Website exclusions and safer editing

You can pause Markflow on exact website hostnames from the local Privacy Center. When those pages are refreshed, the extension does not load saved annotations for those hosts. Exclusions do not change Chrome's host access permission. When separate tabs edit the same annotation, the extension detects concurrent changes and avoids silently overwriting a saved version; a local JSON safety copy can be downloaded.

Permissions

Access to HTTP/HTTPS pages is needed to display the annotation toolbar, follow selected text, and restore annotations on supported pages. The Chrome storage permission supports local settings and migration.

Deletion and security

You can remove annotations using the manager. Removing the extension or clearing Chrome profile data may erase all notes. Markflow v2.0 provides a manual JSON backup/restore feature in the Library dashboard but no cloud backup or HTML export. Save backup copies securely because they may contain private comments and excerpts of webpages.

Contact and corrections

For questions, feature requests and corrections to this policy, use the Issues tab on the GitHub repository from which you downloaded Markflow.
